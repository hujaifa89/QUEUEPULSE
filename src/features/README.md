# QueuePulse Features

Feature-sliced modules for QueuePulse:
- `queue/`: Controller UI, token slip, schemas, eta.ts (Phases 3, 5, 6)
- `live/`: Realtime subscription hook, polling fallback (Phase 6)
- `notifications/`: Push client, outbox processing, SMS adapter (Phase 7)
- `reports/`: Reporting analytics (Phase 8)
- `admin/`: Platform admin management (Phase 4)
